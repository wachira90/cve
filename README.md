# CVE 

**CVE** ย่อมาจาก **Common Vulnerabilities and Exposures**

### ข้อมูลเบื้องต้นเกี่ยวกับ CVE
* **ความหมาย:** เป็นระบบฐานข้อมูลและรายการรหัสอ้างอิงสากลที่รวบรวมช่องโหว่ด้านความปลอดภัย (Vulnerabilities) และความเสี่ยงที่เปิดเผยต่อสาธารณะในซอฟต์แวร์หรือฮาร์ดแวร์
* **หน้าที่:** ทำหน้าที่เป็น "ทะเบียนราษฎร์" หรือรหัสบัตรประชาชนของช่องโหว่แต่ละรายการ เพื่อให้ทีมนักพัฒนา, ผู้ผลิตซอฟต์แวร์ และผู้ดูแลระบบไอทีทั่วโลก สามารถพูดคุยและเข้าใจตรงกันว่ากำลังพูดถึงปัญหาเดียวกัน
* **รูปแบบรหัส:** จะขึ้นต้นด้วย `CVE-` ตามด้วยปีที่ออกรหัส และตามด้วยเลขลำดับ (เช่น `CVE-2021-3456`)
* **ผู้ดูแลโครงการ:** ดำเนินงานโดยองค์กรไม่แสวงหาผลกำไรชื่อ **MITRE Corporation** และได้รับการสนับสนุนทุนจากหน่วยงานรัฐบาลสหรัฐอเมริกา (CISA / กระทรวงความมั่นคงแห่งมาตุภูมิ)

สามารถศึกษาเพิ่มเติมหรือค้นหารายชื่อช่องโหว่ได้ที่ [CVE List Search](https://www.cve.org)
